About the project

A Python desktop player built with CustomTkinter. Choose a music folder, select tracks, create playlists, seek through a song and adjust volume. Playback includes pause and resume, repeat-one, repeat-all and random modes. The interface reads track metadata and provides light and dark artwork. The local source identifies itself as version 18; the README still lists a visualizer as unfinished.
